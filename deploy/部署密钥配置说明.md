# 部署密钥配置说明（内部团队）

本仓库**不含真实密钥**（出于安全，密钥不进 git 历史）。clone 后请按下面步骤，把团队负责人单独提供的密钥填入本地模板，即可运行。

---

## 一、需要从团队负责人处获取的密钥

| 环境变量 | 用途 | 必需 |
| --- | --- | --- |
| `DB_PASSWORD` | PostgreSQL / 超管账号密码 | 必需 |
| `DEEPSEEK_API_KEY` | DeepSeek 文本生成 | 必需 |
| `GEMINI_TEXT_API_KEY` | Gemini 文本（走 laozhang 网关，`sk-` 开头） | 必需 |
| `GEMINI_IMAGE_API_KEY` | Gemini 图像（走 laozhang 网关） | 必需 |
| `ARK_API_KEY` | 火山引擎 ARK：豆包图像 / Seedance 视频 | 必需 |
| `MINIMAX_API_KEY` | MiniMax 视频 / TTS / 音乐（JWT，`eyJ` 开头） | 必需 |
| `SORA2_API_KEY` | Sora2 视频（laozhang；Veo 缺省回退此 key） | 必需 |
| `DASHSCOPE_API_KEY` | 阿里云百炼：Wan2.6 / Kling / Vidu / HappyHorse 视频 | 必需 |
| `VEO_API_KEY` | Veo 视频（缺省回退 SORA2_API_KEY） | 可选 |
| `SEEDANCE_API_KEY` | Seedance（缺省回退 ARK_API_KEY） | 可选 |
| `GPT_IMAGE_API_KEY` / `SORA2_GPT_IMAGE_API_KEY` | 分镜页 GPT Image 2（laozhang 两个令牌分组） | 可选 |

> 重要：Gemini **TTS** 用的是 Google 原生 `AIza` key（官方端点）；Gemini **文本/图像** 用的是 laozhang 网关的 `sk-` key。两者不同，别填混。

## 二、Windows 本地部署

1. 复制启动脚本模板并填入密钥：
   ```powershell
   cd deploy
   Copy-Item local_start.example.ps1 local_start.ps1
   # 用编辑器打开 local_start.ps1，把所有 <FILL_ME_*> 替换为真实密钥
   ```
2. （可选）前端环境变量：
   ```powershell
   Copy-Item new_html\.env.example new_html\.env
   # 填入 <FILL_ME_*>
   ```
3. 启动 / 停止：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\local_start.ps1
   powershell -ExecutionPolicy Bypass -File .\local_stop.ps1
   ```
4. 访问 `http://localhost:6006/projects`。管理员登录密码需通过 `ADMIN_PASSWORD` 显式配置；仅本地开发可设置 `ALLOW_DEV_ADMIN_PASSWORD=true` 后使用临时弱口令 `admin / admin123`。

前置依赖：本机需有 Docker（脚本会自动拉起 `drama-postgres` / `drama-redis` 容器）。

- 密钥仅通过公司密码管理器 / 加密渠道传递，不要发到聊天群、issue、commit message 里。
