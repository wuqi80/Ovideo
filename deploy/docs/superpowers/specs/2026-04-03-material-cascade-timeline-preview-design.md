# 素材绑定级联 + 时间轴折叠预览 设计文档

> 日期: 2026-04-03
> 状态: 已确认

## 概述

两个独立功能改进，均为纯前端修改，无后端变动。

1. **素材绑定级联**：在素材页面绑定角色/场景时，自动向后续未绑定的镜头级联同步
2. **时间轴折叠 + 画面预览**：分镜页面底部时间轴支持折叠，播放时增加画面预览区

---

## 功能一：素材绑定级联

### 选定方案

静默级联 + 左侧列表实时反馈 + 解绑弹窗确认

### 核心规则

- **方向**：只向后级联（当前镜头 → 末尾），不向前
- **条件**：目标镜头必须包含相同 tag（角色名/场景名），且该 tag 尚未绑定
- **角色 + 场景**：两者使用相同的级联逻辑
- **绑定**：静默级联 + toast 提示
- **解绑**：弹窗确认是否级联

### 场景矩阵

| 编号 | 操作 | 后续镜头状态 | 预期行为 |
|------|------|-------------|---------|
| S1 | 镜头2绑定女主→X | 3/4/5 未绑定 | 全部级联 |
| S2 | 镜头2绑定女主→X | 3已绑定Y，4/5未绑定 | 跳过3，级联4/5 |
| S3 | 镜头2绑定女主→X | 4不含"女主" | 跳过4 |
| S4 | 最后一个镜头绑定 | 无后续 | 仅绑定当前 |
| S5 | 镜头2改绑X→Y | 3绑X，4未绑 | 跳过3，级联4 |
| S6 | 镜头2解绑女主 | 后续有绑定 | 弹窗确认 |
| S7 | 场景绑定级联 | 后续含同场景 | 同角色逻辑 |
| S8 | 镜头2绑定 | 镜头1未绑定 | 不动（不向前） |

### 数据结构（不变）

`storyboardItem.boundAssets` 数组中的条目格式：

- `char:角色名` — 表示该镜头包含此角色
- `scene:场景名` — 表示该镜头包含此场景
- `sel:tagName:materialId` — 表示该 tag 已绑定到指定素材
- `nosel:tagName` — 表示该 tag 已解绑

### 绑定级联流程

```
handleBindMaterial(shotId, tagName, materialId):
  1. 保存当前镜头的绑定（现有逻辑）
  2. 找到当前镜头在 storyboardItems 中的 index
  3. 遍历 index+1 到末尾的所有镜头：
     a. 检查 boundAssets 中是否有 char:tagName 或 scene:tagName
        → 没有则跳过（该镜头不含此 tag）
     b. 检查 boundAssets 中是否已有 sel:tagName:*
        → 已有则跳过（已绑定，不覆盖）
     c. 构建新的 boundAssets，添加 sel:tagName:materialId
     d. 调用 saveStoryboardItem 保存
  4. 显示 toast："已同步绑定到后续 N 个镜头"（N=0 时不显示）
```

### 解绑确认流程

```
handleUnbindMaterial(shotId, tagName):
  1. 扫描后续镜头中有多少个包含 sel:tagName:* 的
  2. 如果 count > 0：
     → 弹窗："后续还有 N 个镜头绑定了此角色/场景，是否一起解绑？"
     → 选项: [仅当前镜头] [全部解绑]
  3. 如果 count == 0：
     → 直接解绑当前镜头（无弹窗）
  4. 根据用户选择执行解绑
```

### 涉及文件

- `new_html/pages/MaterialsPage.tsx`：修改 `handleBindMaterial`（增加级联循环）、修改 `handleUnbindMaterial`（增加弹窗逻辑）
- `new_html/components/MaterialPage.tsx`：增加 toast 组件（或使用现有的通知机制）

## 功能二：时间轴折叠 + 画面预览

### 选定方案

折叠面板 + 内嵌预览区

### 折叠功能

- `StoryboardGenPage` 增加 `timelineCollapsed` state（默认展开）
- 收起时：仅显示一行标题栏 + 展开按钮
- 展开时：显示预览区 + 完整时间轴轨道

### 画面预览

在 `TimelineTrack` 组件中增加 `showPreview` prop：

- `showPreview=true` 时，轨道左侧显示一个固定大小的预览区（约 200x120px）
- 预览区显示当前播放位置对应的分镜图片
- 查找逻辑：从 `clips` 中筛选 `track === 'image'`，找到 `startMs <= currentTimeMs < startMs + durationMs` 的 clip，显示其 `imageUrl`
- 无对应图片时显示占位符

### 布局设计

```
展开状态:

│  分镜生成工作区（flex-1）                  │

│ ┌──────────┬────────────────────────────┐│
│ │ 预览区    │  播放控制 + 时间轨道         ││

└─────────────────────────────────────────┘
```

### 涉及文件

- `new_html/pages/StoryboardGenPage.tsx`：增加 `timelineCollapsed` 状态、折叠 UI 逻辑
- `new_html/components/TimelineTrack.tsx`：增加 `showPreview` prop、左侧预览区渲染、当前帧查找逻辑
