# SPTI.AI 品牌关系说明

SPTI.ai（**Story Production Technology Intelligence**）意为“故事生产技术智能”，是一个基于 AI 能力打造的漫剧生产智能平台。

这个命名和产品核心链路直接对应：Story 指文本、剧本和分镜源头，Production 指从分镜到镜头设计、素材、视频、配音和成片的生产闭环，Technology Intelligence 指平台用多模型、工作流和任务编排把创作变成可执行的智能生产流程。

因此对外主名称统一为 **SPTI.AI 漫剧创作平台**；Logo 使用“SPTI”字母结构、播放三角和分镜/剧本帧的组合，表达“故事进入智能生产线”的关系。原 MECHA / mecha.one 不再作为公开主品牌和默认访问域名，仅在必要的历史兼容、内部环境变量或旧记录中短期保留。
