# SPTI.AI final logo masters

Approved production artwork backed up on 2026-07-30.

## Master files

- `spti-ai-logo-light-blue-master.png`: blue wordmark for light interfaces.
- `spti-ai-logo-dark-white-master.png`: white wordmark for dark interfaces.
- `spti-ai-mark-master.png`: square brand mark extracted from the approved light master.

Both lockups are transparent RGBA PNG files at 1327 × 368. The mark is a
transparent RGBA PNG at 368 × 368. The light and dark lockups share the same
canvas and crop, so switching themes does not shift the brand position.

## Production usage

- Flow-based production pages and other light surfaces use the blue lockup.
- Only the free-canvas dark theme uses the white lockup.
- Favicons, app icons, loading states, card placeholders, and compact admin
  placements use the shared blue-framed mark.

The approved artwork was produced with the built-in image generation workflow.
Production derivatives are stored in `deploy/static/branding` and
`deploy/static`.
